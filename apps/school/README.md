# @smw/school

Each school's public website and its `/app` dashboard for admins, teachers, students and parents. This is the tutorial dashboard, moved here unchanged.

- Address in production: `<slug>.yourbrand.com` or the school's own domain
- Local address: http://localhost:3000
- Run only this app with `pnpm --filter @smw/school dev`

`pnpm lint` does not work yet. Next.js 16 removed `next lint`; ticket P0-05 replaces it.
