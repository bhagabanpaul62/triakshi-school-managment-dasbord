# @smw/auth

Identity: sessions, password hashing and role permission checks.

## What goes here

- Host-only session cookies, so a session never leaks between schools
- Password hashing
- Role permission map: which role can do which action in which feature
- Later: platform staff login with mandatory two-factor, and bearer tokens for the mobile app

## When

Phase 0, after the auth spike in ticket P0-09.
