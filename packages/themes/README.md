# @smw/themes

School themes: the token schema, presets, and the CSS variables each app writes on `:root`.

## What goes here

- zod schema for theme tokens: colours, radius, font, logo, favicon
- Preset themes. The default reproduces today's tutorial colours exactly
- CSS variable output used by the panel, the website, the login page, emails and PDFs
- WCAG AA contrast check that blocks unreadable colour combinations

## When

Phase 0 for CSS variables, Phase 4 for the theme editor.
