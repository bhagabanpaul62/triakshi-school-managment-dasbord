# @smw/site-templates

School public websites: templates, section types and the renderer.

## What goes here

- Template contract: key, name, kind (preset or custom), supported sections, layout
- Section types with zod schemas: hero, rich text, stats, gallery, news, events, staff list, testimonials, admission enquiry, contact
- Three preset templates at launch, plus custom templates made for one school
