# @smw/onboarding

School onboarding logic, shared by the marketing site (self-serve signup), the console (sales-assisted) and the school app (setup wizard).

## What goes here

- Signup: create a school in trial status and its admin account
- Subdomain rules: lowercase, unique, not a reserved word
- Setup wizard steps: academic year, classes and sections, subjects, student import, staff invites, website
